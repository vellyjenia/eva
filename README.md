# ai-lifechanger.com — собранный сайт

Это **готовая статика**: HTML, CSS, JS, шрифты и картинки. Ни сервера, ни базы,
ни сборки на хостинге не нужно — содержимое этой папки раздаётся как есть.

## Как это обновляется

Файлы здесь **собираются программой и правятся не здесь.** Исходники (шаблоны
и тексты на трёх языках) лежат в репозитории разработки; там правится текст,
запускается сборщик, и результат приезжает сюда целиком. Правка прямо в этих
файлах пропадёт при следующей сборке.

Обновление: содержимое папки `site/` из репозитория разработки копируется
**в корень** этого репозитория, полностью заменяя прежнее. GitHub Pages умеет
отдавать только корень ветки или `/docs`, подкаталог не годится.

## Чего нельзя потерять при копировании

Эти файлы не видны ни в файловом менеджере, ни в веб-интерфейсе GitHub:

| Файл | Что будет, если потерять |
|---|---|
| `.nojekyll` | Jekyll молча выбросит `.well-known/` — отвалится `security.txt` |
| `CNAME` | отвалится привязка домена, сайт уедет на `*.github.io` |
| `.well-known/security.txt` | пропадёт контакт для сообщений об уязвимостях |

Копировать надо вместе со скрытыми файлами: `cp -a site/. .` или
`rsync -a site/ .` — перетаскиванием мышкой они не переносятся.

## Что здесь лежит

| Путь | Что это |
|---|---|
| `index.html`, `ru/`, `en/` | главная на трёх языках. Корень `/` — украинский |
| `privacy.html`, `terms.html` | юридические страницы, тоже в трёх языках |
| `404.html` | страница ошибки, язык определяется по адресу |
| `assets/` | шрифты, картинки, иконки, скрипты и стили |
| `go/` | короткие ссылки для печати и QR: `/go/ig`, `/go/qr` и прочие |
| `robots.txt`, `sitemap.xml`, `llms.txt` | файлы для поисковиков и AI-ассистентов |
| `bab768d2eb0f619e43c993a0735be99c.txt` | ключ IndexNow, трогать не надо |
| `_redirects` | нужен другому хостингу, на GitHub Pages не работает и не мешает |

Все кнопки сайта ведут в Telegram-бот и несут в ссылке метку: откуда пришёл
человек, каким языком читал сайт и что собрал в калькуляторе цен. Разбирать её
должен бот — схема и готовый код лежат в репозитории разработки, `docs/utm.md`.
